# Mukhyaprana – Resume

A simple, lightweight static website for hosting my professional resume using Vercel.

## Live Resume

- Website: https://mukhyaprana-bagalkotkar-resume.vercel.app/
- Direct PDF: https://resume-mukhyaprana.vercel.app/Mukhyaprana_Resume.pdf

## Project Structure

```
resume-host/
│
├── public/
│   └── Mukhyaprana_Resume.pdf
│
├── index.html
├── vercel.json
├── README.md
├── .gitignore
└── LICENSE
```

## Technologies Used

- HTML5
- Static PDF Hosting
- GitHub
- Vercel

## Deployment

This project is deployed through Vercel and connected directly to its GitHub repository.

Whenever new commits or updates are pushed to the connected branch on GitHub, Vercel automatically detects the changes and triggers an instant redeployment.
